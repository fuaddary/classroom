## 💡 Prompt AI

Salin prompt berikut ke AI (Claude / ChatGPT / Gemini). **Lampirkan RPS** sebagai konteks untuk hasil terbaik.

```
Berdasarkan RPS 16 minggu MK Pemrograman Web [lampirkan RPS], susun tabel
linimasa yang menandai minggu mana saja ada tenggat tugas/ujian beserta
bobotnya, untuk ditempel di section pengantar myITS Classroom.
Hasilkan dalam format tabel HTML inline-style siap tempel Moodle.
```

---

## 📋 Contoh Hasil — HTML Siap Tempel ke Moodle

> Salin kode di bawah → di Moodle klik ikon **`</>` Edit HTML source** → tempel → klik Update.

```html
<!-- file tidak ditemukan -->
```
